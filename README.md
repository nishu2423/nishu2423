## Featured project

### [AdventureWorks — Azure Data Engineering](https://github.com/nishu2423/AdventureWorkLoad_Project)

An end-to-end data engineering project built around the Medallion Architecture.

- Ingests AdventureWorks datasets using Azure Data Factory.
- Stores raw data in Azure Data Lake Storage Gen2.
- Transforms data with PySpark into Silver-layer datasets.
- Uses Azure Synapse Serverless SQL for analytics.
- Includes metadata-driven ingestion and reusable data-quality checks.
